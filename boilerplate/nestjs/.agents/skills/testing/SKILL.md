# Testing

This file defines anything you need to know to write unit tests.

## File convetions

- The unit testing file name should be `{file_to_test}.spec.ts`
- The files should be placed in this structure

```txt
|--- folder-a
|    |--- tests
|    |    |--- a.service.spec.ts
|    |--- a.service.ts
```
